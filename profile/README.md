## 知識型站點

我們把研究過程中整理的知識，做成可以長期查閱的獨立站點。

### 📐 [ArkiWiki 建築維基](https://arkiwiki.autodesignlab.org/)

以可追溯建築資料庫為底座，透過統計與文字分析整理並視覺化知識，連結 IFC BIM 模型法規自動檢討與系統性學習。

### 🀄 [StatMahjong 日本麻將教學](https://statmahjong.autodesignlab.org/)

用統計學與機率分析重新理解立直麻將，整理牌效率、點數計算、攻守判斷、麻將術語與日麻牌理知識庫。

### 🎹 [Piano Flow 線上 MIDI 鋼琴練習](https://pianomidi.autodesignlab.org/)

連接 MIDI 鍵盤，跟著瀑布流音符練習鋼琴；從公開授權曲庫選曲，獲得即時判定、分數與演奏回饋。
